1. What is Private Key Encryption with PKCS#1 v1.5?

            

              In classical asymmetric cryptography, encryption is conventionally done with a public key and decryption with a private key. However, many enterprise and legacy architectures (including payment gateways, banking hardware security modules, and custom signature-envelope protocols) perform encryption with a private key and decryption with the corresponding public key.
            

            

              Under PKCS#1 v1.5 (RFC 2313 & RFC 3447), the encryption block \(EB\) has the format:
            

            
EB = 0x00 || BT || PS || 0x00 || D

            
    
              
  • BT = 0x01: Block Type 1. The padding string \(PS\) is filled with octets of value 0xFF (at least 8 bytes). This is the exact block format used by OpenSSL (RSA_private_encrypt), Node.js (crypto.privateEncrypt), and Java SunJCE.
    • 
              
  • BT = 0x02: Block Type 2. The padding string \(PS\) is filled with pseudorandom non-zero octets.
    • 
            


            
2. Cross-Language Code Examples

            
            

              

                Python (Using this tool or cryptography module)
                
# CLI Usage:
python rsa_tool.py encrypt -k private_key.pem -i "Hello World"
python rsa_tool.py decrypt -k public_key.pem -i "<base64_ciphertext>"

# Python API:
import rsa_crypto
priv = rsa_crypto.load_private_key(open("private_key.pem").read())
pub = rsa_crypto.load_public_key(open("public_key.pem").read())

ciphertext = rsa_crypto.encrypt_private(b"Hello World", priv, block_type=1)
plaintext = rsa_crypto.decrypt_public(ciphertext, pub)
print(plaintext.decode("utf-8")) # "Hello World"

              


              

                Node.js (Built-in crypto module)
                
const crypto = require('crypto');
const fs = require('fs');

const privateKey = fs.readFileSync('private_key.pem', 'utf8');
const publicKey = fs.readFileSync('public_key.pem', 'utf8');

// Encrypt with Private Key (PKCS#1 v1.5)
const cipher = crypto.privateEncrypt({
  key: privateKey,
  padding: crypto.constants.RSA_PKCS1_PADDING
}, Buffer.from('Hello World'));

// Decrypt with Public Key (PKCS#1 v1.5)
const plain = crypto.publicDecrypt({
  key: publicKey,
  padding: crypto.constants.RSA_PKCS1_PADDING
}, cipher);

console.log(plain.toString()); // "Hello World"

              


              

                Java (Standard SunJCE Provider)
                
import javax.crypto.Cipher;
import java.security.PrivateKey;
import java.security.PublicKey;

Cipher cipher = Cipher.getInstance("RSA/ECB/PKCS1Padding");

// Encrypt with PrivateKey
cipher.init(Cipher.ENCRYPT_MODE, privateKey);
byte[] ciphertext = cipher.doFinal("Hello World".getBytes(StandardCharsets.UTF_8));

// Decrypt with PublicKey
cipher.init(Cipher.DECRYPT_MODE, publicKey);
byte[] plaintext = cipher.doFinal(ciphertext);
System.out.println(new String(plaintext, StandardCharsets.UTF_8)); // "Hello World"
